# Release Notes: AgentOps SDK — Customer-Neutral Initial Release (`v1.0.0`)

## Module: `agentops_sdk`

**Release Version:** `v1.0.0`
**Target Package:** `agentops-sdk==1.0.0` (`requires-python >=3.11,<3.15`, `setuptools.build_meta` backend)
**Default Wheel Artifact:** `agentops_sdk-1.0.0-py3-none-any.whl`
**Git Branch:** `main`
**Release Date:** `2026-11-19`

---

## 1. Overview

> **Goal:** Deliver the customer-neutral `v1.0.0` initial release of the Google Enterprise AgentOps Governance Framework & SDK (`agentops-sdk`), providing unified Google Cloud observability, 23-CWE defense-in-depth security controls, AST-enforced SQL governance, fail-closed MCP tooling, and CI/CD evaluation quality gates built on a clean Hexagonal Ports & Adapters architecture.

The **AgentOps Governance Framework & SDK** (`agentops_sdk`, version `1.0.0`) establishes a modular 12-subpackage Python platform (`domain`, `ports`, `config`, `security`, `audit`, `telemetry`, `resilience`, `sql`, `prompts`, `evaluation`, `memory`, `feature_store`) paired with a zero-trust FastMCP gateway (`mcp_servers/src/`) and operational automation tools (`tools/`).

Core runtime capabilities rely on typed `typing.Protocol` port contracts in `agentops_sdk.ports` and fail-closed native GCP adapters, while explicit hermetic adapters (`InMemory*`, `LocalRuleSafetyScanner`, `RegexPrivacyScrubber`) enable deterministic offline testing without hidden simulation fallbacks. Packaging lives at the repository root in [`pyproject.toml`](../pyproject.toml), shipping [`sdk/src/agentops_sdk/py.typed`](../sdk/src/agentops_sdk/py.typed) (PEP 561) and exposing **219** symbols through the PEP 562 lazy root facade in [`sdk/src/agentops_sdk/__init__.py`](../sdk/src/agentops_sdk/__init__.py).

## 2. Features & Architectural Highlights

### 2.1. Package Surface, Exports & Clean Hexagonal Architecture

*   **Root Packaging & Distribution**: Built from root [`pyproject.toml`](../pyproject.toml) using `setuptools.build_meta` (`requires = ["setuptools>=61.0.0", "wheel"]`) over the `sdk/src` source directory (`where = ["sdk/src"]`), dynamically reading `__version__ = "1.0.0"` from [`sdk/src/agentops_sdk/__init__.py`](../sdk/src/agentops_sdk/__init__.py), pinning `pyjwt>=2.10.0` and `sqlglot>=30.0.0` (`exp.Expr`), and bundling `py.typed`.
*   **219 Top-Level Exports (PEP 562 Lazy Facade)**: `__all__` exposes **219** symbols combining `1` `__version__`, **12** subpackages in `_SUBMODULES` (`audit`, `config`, `domain`, `evaluation`, `feature_store`, `memory`, `ports`, `prompts`, `resilience`, `security`, `sql`, `telemetry`), and **206** unique lazily loaded re-exports in `_EXPORT_MAP` via `__getattr__` and `__dir__`. Note that [`agentops_sdk.domain`](../sdk/src/agentops_sdk/domain/__init__.py) exports domain submodules (`context`, `exceptions`, `lifecycle`, `models`, `predicates`, `templating`, `validation`), while domain models, exceptions, and context helpers are re-exported directly from top-level `agentops_sdk`. `BoundedTTLCache` ([`sdk/src/agentops_sdk/domain/lifecycle.py`](../sdk/src/agentops_sdk/domain/lifecycle.py)) enforces strict `int`/non-`bool` validation on `maxsize` and `ttl_seconds`.
*   **7 Optional Extras & Pytest Entry Point**: `[project.optional-dependencies]` defines **7** extras—`cloudsql`, `eval`, `ragas`, `feature-store`, `mcp`, `all`, and `dev`—while core Google Cloud client libraries live directly in base `dependencies`. `[project.entry-points.pytest11]` registers `agentops_eval = "agentops_sdk.pytest_plugin"`; release consolidation runs via `python -m tools.release_notes.consolidate` (no `[project.scripts]` CLI entry point is registered).

### 2.2. 23-CWE Defense-in-Depth Security Hardening

All **23** CWE classes documented in [`docs/security_and_verification.md`](../docs/security_and_verification.md) are enforced across the SDK, MCP gateway, pytest plugin, and observability utilities:

*   **Zero-Trust JWT, Entra ID & SSRF-Hardened JWKS (`CWE-918`, `CWE-347`, `CWE-287`, `CWE-327`, `CWE-798`, `CWE-290`)**:
    *   `JWTAuthEngine` ([`sdk/src/agentops_sdk/security/auth.py`](../sdk/src/agentops_sdk/security/auth.py)) and `SafeJWKClient` ([`sdk/src/agentops_sdk/security/_jwks.py`](../sdk/src/agentops_sdk/security/_jwks.py)) pin `algorithms=("RS256",)` for JWKS/PEM (`parse_rsa_public_pem`) and `algorithms=("HS256",)` for symmetric keys, validate `exp`, fail-closed RS256 `audience` + `issuer` (including `build_entra_issuer`), and `type == expected_type` claims while supporting OIDC typeless `RS256` access tokens.
    *   Supports `AGENTOPS_IDENTITY__*` / `ENTRA_*` / `JWT_PUBLIC_KEY` (`MCP_JWT_PUBLIC_KEY`) env precedence, maps Entra `"tid"` claims to `"tenant_id"` for RLS, separates `ENVIRONMENT` caches, handles `ConfigurationError` cleanly, and rejects `bool`/non-scalar `tenant_id` values in `auth.py` and [`mcp_servers/src/auth_guard.py`](../mcp_servers/src/auth_guard.py).
    *   Enforces HTTPS JWKS URLs with host allowlists, blocks private/loopback/link-local/CGNAT IPs, re-checks DNS inside `fetch_data()`, and rejects HTTP `3xx` redirects.
    *   `hash_password()` / `verify_password()` apply 600,000-iteration PBKDF2-HMAC-SHA256 with 16-byte salts and constant-time comparison. Outside development (`ENVIRONMENT` not in `{"dev", "development", "local", "test"}`), `JWTAuthEngine` fails closed without configured JWKS/PEM or a `>=32`-byte `JWT_SECRET_KEY`.
    *   `@pass_user_identity` and `@inject_secret` ([`sdk/src/agentops_sdk/security/identity.py`](../sdk/src/agentops_sdk/security/identity.py)) preserve `ExecutionScope` `ContextVar` isolation across sync/async boundaries and prevent caller argument spoofing.
*   **Fail-Closed Secret Management (`CWE-636`, `CWE-20`, `CWE-798`)**:
    *   `SecretManagerStore` ([`sdk/src/agentops_sdk/security/secrets.py`](../sdk/src/agentops_sdk/security/secrets.py)) uses a 256-stripe singleflight `BoundedTTLCache(maxsize=512, ttl_seconds=300.0)` with multi-version revocation eviction (`_evict_secret_versions`) on `PermissionDenied`, `NotFound`, or `delete_secret()`, strict `secret_id`/`version` validation, and zero env/default fallback (`InMemorySecretStore` is provided explicitly for tests). `DatabaseSettings.password` and `databricks_token` are wrapped in `pydantic.SecretStr`.
*   **Fail-Closed Cloud Model Armor & Regional Cloud DLP (`CWE-636`)**:
    *   `SecurityGuard(fail_closed=True)` and `CloudModelArmorScanner` ([`sdk/src/agentops_sdk/security/guard.py`](../sdk/src/agentops_sdk/security/guard.py), [`model_armor.py`](../sdk/src/agentops_sdk/security/model_armor.py)) pool regional `modelarmor_v1.ModelArmorClient` instances, evaluate all **5** threat filters (`pi_and_jailbreak`, `rai`, `malicious_uri`, `csam`, `virus_scan`) plus SDP inspect/deidentify results, and fail closed (`SecurityVerdict.BLOCK` / `SecurityViolationError`). Inject `LocalRuleSafetyScanner()` explicitly for offline testing. See [`docs/model_armor_security_layer_guide.md`](../docs/model_armor_security_layer_guide.md).
    *   `OutputDLPSanitizer` and `GoogleDLPScrubber` ([`sdk/src/agentops_sdk/security/dlp.py`](../sdk/src/agentops_sdk/security/dlp.py)) pool regional `dlp_v2.DlpServiceClient` instances, chunk oversized payloads at `<= 400,000` UTF-8 bytes, and raise `PrivacyScrubError` on errors. Inject `RegexPrivacyScrubber()` explicitly for offline testing. See [`docs/privacy_dlp_design.md`](../docs/privacy_dlp_design.md).
*   **Scope-Aware AST SQL Governance & Parse-Tree Row-Level Security (`CWE-89`, `CWE-636`)**:
    *   `SQLASTValidator`, `validate_sql_query`, and `@validate_sql_query_decorator` ([`sdk/src/agentops_sdk/sql/_ast_rules.py`](../sdk/src/agentops_sdk/sql/_ast_rules.py), [`ast_guard.py`](../sdk/src/agentops_sdk/sql/ast_guard.py), [`decorators.py`](../sdk/src/agentops_sdk/sql/decorators.py)) enforce single-statement read-only `sqlglot` (`exp.Expr`) roots, block DML/DDL/TVFs/system schemas, `exp.TableFromRows`, `PIVOT`/`UNPIVOT`, column-list aliases, and hidden comment DDL, support dialect-normalized CTEs, sole-`FROM` `ML.PREDICT`, and `dataset.*` wildcards, and reject empty or bare `"*"` table allowlists.
    *   `RowLevelPolicyEngine` and `apply_row_level_policy` ([`sdk/src/agentops_sdk/sql/_rls_helpers.py`](../sdk/src/agentops_sdk/sql/_rls_helpers.py), [`rls.py`](../sdk/src/agentops_sdk/sql/rls.py)) unwrap `Subquery`/`TableSample`/`Paren` table wrappers, preserve `LEFT JOIN ... ON` predicates, handle sole-`FROM` `ML.PREDICT` outer output predicates, fail closed on empty `target_tables`, enforce role-gated admin bypass (`role in {"admin", "superadmin"}`), parenthesize pre-existing `WHERE ... OR ...` clauses before injecting tenant predicates, and run post-rewrite `_verify_all_tables_covered`.
*   **Zero-Trust FastMCP Gateway (`CWE-306`, `CWE-288`, `CWE-203`, `CWE-284`, `CWE-319`)**:
    *   [`mcp_servers/src/server.py`](../mcp_servers/src/server.py), [`auth_guard.py`](../mcp_servers/src/auth_guard.py), and [`_http.py`](../mcp_servers/src/_http.py) expose **3** tools—`query_database_tool(query_template, parameters=None)`, `query_databricks_tool(query_template, parameters=None)`, and `query_feature_store_tool(entity_type, entity_ids, features)`—with **zero** `auth_token` parameter exposed to LLMs.
    *   ASGI `HeaderBindingMiddleware` extracts per-request HTTP `Authorization: Bearer` headers, `MCP_REQUIRE_AUTH` defaults to `"true"` before SQL AST/RLS evaluation (preventing pre-auth table enumeration), `authorize_feature_store_tenant()` enforces `MCP_ALLOWED_ENTITY_TYPES` and tenant scoping, `CONNECTOR_API_URL` enforces `https://` for non-loopback targets, and [`mcp_servers/Dockerfile`](../mcp_servers/Dockerfile) executes under non-root `mcpuser`.
*   **Sandbox, Path, Code-Eval, CLI Redaction & Supply-Chain Hygiene (`CWE-94`, `CWE-1336`, `CWE-22`, `CWE-59`, `CWE-732`, `CWE-79`, `CWE-117`, `CWE-209`, `CWE-532`, `CWE-78`, `CWE-829`, `CWE-862`)**:
    *   `_BoundedSandboxEnvironment` restricts Jinja2 template evaluation; `validate_metric_code` enforces a strict Python AST allowlist up to `16,384` chars; local sinks, YAML prompts, and pytest reports reject `..`/symlinks (`O_NOFOLLOW`) and enforce `0o700` dir / `0o600` file modes; `_esc` / `_safe_url` harden markdown reports; `sanitize_log_field` / `scrub_sensitive_text` and CLI output redaction in `tools/` prevent CRLF injection and redact secrets/PII from spans, audit entries, and terminal logs; [`tools/observability/setup_log_routers.sh`](../tools/observability/setup_log_routers.sh) passes arguments via `sys.argv` into a quoted heredoc.
    *   Reference FastAPI gateways enforce owner/admin RBAC (`_require_owner_or_admin`) and sanitized `401`/`403` error payloads without leaking internal exception messages; container, Compose, and CI manifests pin `@sha256:` image digests, `127.0.0.1` loopback-only Docker Compose bindings, and 40-character commit-SHA GitHub Action pins.

## 4. Packaging, Installation & CI/CD Tooling

### 4.1. Installing `agentops-sdk==1.0.0`

[`pyproject.toml`](../pyproject.toml) resides at the repository root and builds `agentops_sdk-1.0.0-py3-none-any.whl` cleanly via `setuptools.build_meta`.

```bash
# Option 1: GitHub CLI (Recommended for private Enterprise SSO releases)
gh release download v1.0.0 \
  --repo ORG/agentops-sdk \
  --pattern "*.whl" \
  --dir /tmp --clobber && \
pip install "/tmp/agentops_sdk-1.0.0-py3-none-any.whl"

# Option 2: Direct pip install from repository root via Git+SSH (base or with extras)
pip install "agentops-sdk @ git+ssh://git@github.com/<ORG>/<REPO>.git@v1.0.0"
pip install "agentops-sdk[cloudsql,eval] @ git+ssh://git@github.com/<ORG>/<REPO>.git@v1.0.0"

# Option 3: Artifact Registry / PyPI index with modular extras
pip install "agentops-sdk==1.0.0"                 # Core GCP, telemetry, audit, security, SQL, prompts
pip install "agentops-sdk[cloudsql]==1.0.0"        # + Cloud SQL (sqlalchemy, psycopg2-binary)
pip install "agentops-sdk[eval]==1.0.0"            # + Vertex EvalTask & pandas
pip install "agentops-sdk[ragas]==1.0.0"           # + RAGAS evaluator adapter (ragas, datasets)
pip install "agentops-sdk[feature-store]==1.0.0"   # + Vertex Feature Online Store v2
```

```python
from agentops_sdk import (
    AuditLedger,
    SecurityGuard,
    TelemetryContext,
    TelemetryMode,
    VertexMemoryBank,
    configure_telemetry,
    trace_agent_flow,
)

configure_telemetry(mode=TelemetryMode.GCP, project_id="<your-gcp-project-id>")
guard = SecurityGuard(fail_closed=True)
ledger = AuditLedger()  # Defaults to CloudLoggingAuditAdapter (agentops-audit-ledger)
memory = VertexMemoryBank(
    "projects/<your-gcp-project-id>/locations/europe-west4/reasoningEngines/01",
    project_id="<your-gcp-project-id>",
)

ctx = TelemetryContext(
    business_kpi="supply-chain-lookup-latency",
    pl_impact_line="operating-expense-savings",
    project_name="inventory-advisor",
)


@trace_agent_flow(context=ctx, agent_role="advisor")
def handle_prompt(prompt: str, user_id: str) -> str:
    decision = guard.check_input(prompt)
    if not decision.allowed:
        return f"Blocked: {decision.violation_category}"
    memories = memory.retrieve_memories(
        user_id=user_id, query=decision.sanitized_text, limit=3
    )
    return f"Matched {len(memories)} memory item(s)."
```
